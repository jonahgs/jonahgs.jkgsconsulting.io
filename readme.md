# JKGS Consulting website

Public site: https://jkgsconsulting.com/

Static HTML, CSS, and JavaScript hosted by GitHub Pages from the root of `main`.

The homepage introduces operations, practical AI, and ongoing part-time consulting. Dedicated service pages carry the detail. Public contact is email-only; the contact page prepares a message for the visitor to send from their own email app. Do not publish a personal phone number in content, links, or structured data.
