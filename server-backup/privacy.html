Surface Server Backup — Privacy information

Last updated: September 12, 2026.

Surface Server Backup is operated for personal use by the owner of jonahkgs@gmail.com.

Google data access and purpose

The utility requests Google's drive.file permission to create and manage the backup files and folders it creates or is explicitly authorized to access. It uses file contents and metadata to upload encrypted recovery snapshots, list and verify snapshots, restore data and remove older backups. Drive account information may be checked to confirm the intended destination account and available storage.

Storage and protection

Application data and configuration from the personal server are encrypted with Restic before upload to Google Drive. Google OAuth credentials and refresh tokens are stored in private files on the server to permit scheduled backups. The Restic recovery password is stored separately from the uploaded repository.

Sharing and retention

Backup data is stored with Google Drive for the owner's recovery use. The utility does not sell Google user data or use it for advertising. Its configured retention keeps seven daily, four weekly and six monthly snapshots, with cleanup performed weekly. The owner controls access to the destination Drive and any separately retained recovery copies.

Control and contact

The owner can stop the backup service, revoke its Google account authorization, and delete backup files from Drive. Revocation stops future API access; it does not automatically delete previously stored backups. Questions can be sent to jonahkgs@gmail.com.
