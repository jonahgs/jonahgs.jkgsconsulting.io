Personal Backups & Home Assistant

These pages describe the personal backup and home automation applications operated by the owner of jonahkgs@gmail.com. They cover Surface Server Backup and the owner's Home Assistant deployment, including connections identified as Home Assistant and Home Assist Web SDK.

Privacy policy · Terms of use

Backup and recovery

Restic and rclone create encrypted recovery copies of selected server application data and configuration, including Home Assistant's configuration and database. The server application backup runs nightly and stores encrypted snapshots in the owner's Google Drive. Separately configured local server and laptop backups provide additional recovery copies with their own selected files and retention settings.

The Drive connection uploads, lists and verifies backup snapshots, retrieves files for recovery, and removes older snapshots under the configured retention policy. Coverage depends on each backup job's selected files and applications.

Home Assistant connections

  • Google Calendar: displays authorized calendars and events, supports event-based automations, and creates events when requested and permitted.
  • Google Nest: displays authorized device state, receives device events, and supports permitted controls. Camera or doorbell media is accessed only where supported, configured and authorized.
  • Google Assistant SDK: sends text commands and queries to Google Assistant for the owner's selected controls, information requests or broadcasts, and processes the responses.

Each connection uses the Google account and permissions the owner authorizes. The applications support personal and authorized household use.
