Surface Server Backup

Surface Server Backup is a private backup utility operated by the owner of jonahkgs@gmail.com.

It uses Restic and rclone to encrypt application data and configuration from a personal server and store recovery snapshots in the owner's Google Drive. It runs on a nightly schedule.

Google authorization lets the utility create and manage its own backup files and folders, retrieve them for recovery, and remove older snapshots according to its retention settings. It requests the drive.file permission.

Use is limited to the owner's personal backup system. The backup files and Google credentials are not served by this website.
