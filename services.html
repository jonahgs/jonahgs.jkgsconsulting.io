A few practical questions

Before we start.

Do I need to know which service I need?

No. Describe the business and the problem you keep running into. The first conversation helps identify a sensible starting point.

Can we start with an implementation project?

Yes, when the problem and intended change are clear enough to scope the work. If they need more investigation, a focused review can help establish the next step.

Does every project involve AI?

AI is one possible tool. The useful improvement might be a clearer decision, a better handoff, a simple form or a change in responsibilities.

What do we agree before starting?

We agree the problem, intended outcome, scope, deliverables, responsibilities, access, timing and fees. Implementation and any ongoing support have their own agreed scope.

Can a project be done remotely?

Much of the research, process work, reporting and system development can be done remotely across Canada. Ottawa-based visits can be agreed where seeing the work in person would help.
