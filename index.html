How I work

Who is this a problem for?

Start with the people affected. Check whether a change is needed before choosing a solution.

  1. 01 / Signal

    See what happens.

    Trace the process with the people doing it.

  2. 02 / Impact

    Check the impact.

    Look at delays, rework and lost capacity.

  3. 03 / Priority

    Choose a response.

    A clearer process, existing software or a new tool.

  4. 04 / System

    Test it in use.

    Try the change with the team and check the results.
